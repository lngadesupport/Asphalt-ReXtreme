# Branding

## Official executable icon

Starting with **ReXtreme Offline Alpha 0.6**, `AsphaltReXtreme.exe` uses the user-provided **ReXtreme RX icon** as the official executable/application icon.

Requirements:
- embed the icon directly in `AsphaltReXtreme.exe`;
- provide Windows icon sizes for Explorer, shortcuts, taskbar and Start;
- use the same icon for future Offline Edition launchers/installers;
- do not replace it with temporary/generated branding in later builds.

The source artwork is supplied privately by the project owner and is treated as the canonical visual asset.
